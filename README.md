# SistemaTest - User Portal with Login Feature

A simple and elegant user portal with login functionality.

## Features

- ✨ Clean and modern UI design
- 🔐 Secure login with form validation
- 💾 "Remember me" functionality
- 📱 Responsive design
- 🎨 Beautiful gradient theme
- ⚡ Client-side session management

## How to Use

1. Open `index.html` in your web browser
2. Enter one of the demo credentials
3. Click "Login" to access the dashboard
4. Click "Logout" to return to the login page

## Features Implemented

- **Login Page**: Clean interface with username and password fields
- **Form Validation**: Client-side validation for input fields
- **Session Management**: Uses sessionStorage to maintain login state
- **Remember Me**: Option to remember username for future logins
- **Dashboard**: User portal showing session information
- **Logout**: Secure logout functionality

## Technical Details

- Pure HTML, CSS, and JavaScript (no dependencies)
- Client-side validation and authentication
- Responsive design works on all devices
- Modern CSS with gradient backgrounds
- Smooth animations and transitions

## Security Note

This is a demo implementation for testing purposes. In a production environment:
- Authentication should be handled server-side
- Passwords should be hashed and salted
- HTTPS should be used for all communications
- Additional security measures (CSRF tokens, rate limiting, etc.) should be implemented
